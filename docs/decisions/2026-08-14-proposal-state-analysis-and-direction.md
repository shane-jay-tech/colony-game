## 2. 三大核心问题（实测证据）

1. **从未真人 playtest**（文档自 v0.5 反复标注的最大暗雷）。
2. **无头模拟 720 天只到国格 1/6**：定格人口 92/金 9999 饱和/布 0/木 9999 饱和；卡点 = 邦国门槛"布 40 + 祖庙"，贪心策略不产布 → 阶梯可达性未验证。

## 4. 关键洞察

1. 系统广度已超量（七游戏可移植机制约 80% 已实现），继续加系统边际收益低；短板在**可见性与验证**。
2. "下一步该做什么必须永远可见"是七款游戏的共同答案（Anno 供需表/DSP 生产面板/群星情境日志/C:S 里程碑）。
3. 后期无聊的解药已有骨架缺呈现：终局波次/大工程/警惕值已实现，缺玩家可读的全程目标感。

## 7. 落地任务清单（下一阶段直接执行顺序）

### P1 信息可视化（先做）
1. 供需速率面板：HUD 资源 token 悬停/点击显示 日产/日耗/净变化（复用 productionSystem 聚合结果，纯 UI + 数据聚合函数，成本低）。
2. 升格目标面板：点击国格徽章展开「下一国格还差什么」（人口/资源/标志建筑三项清单 + 达成打勾）。
3. 需求因果链提示：资源短缺时提示"缺布→需桑园→需国策X"链路（复用 buildingRegistry 的 upgradeRequires/unlock 数据）。
4. 幸福度→产出升级闭环显性化：阶层需求缺口面板与产出折扣数值直接可见（A2 已有引擎，补呈现）。
- 验收：任一新面板在 1280px 最小宽度可用；纯函数聚合有单测；npm run verify 全绿 + 刷新 exe。

### P2 目标感系统
1. 终局记分牌：终局/通关时多维计分（人口/城邑/盟国/灭国/危机扛过/国格达成）+ 历史最好成绩存档。
2. （可选，成本中）三幕大事件时间轴：蛮夷南下→争霸会盟→末世解体，复用事件/邦交引擎。
3. （可选）通牒式压力事件链（倒计时 + 可见进度条）。
4. （可选，改造采纳/中成本）商路自动化规模跃迁：漕运/驿站/商路中后期自动调配资源（对标 DSP 物流塔），消除后期重复微操。
- 验收：沙盒登顶或故事结局时能看到记分牌；记分牌数据入存档。

### P3 故事填肉
1. 七卷事件 23→35+（每章 5 个 A 级决策事件），素材取自 _tianxiaren_source.md。
2. 叙事报文扩充（每章 8 条目标）。
3. 史官评语覆盖七章。
- 验收：故事模式一章内事件密度可感知；copyBias 守护不破。

### P4 美术收尾与发布
1. 麻田/锡矿 2 张建筑图（内置 image_gen 不可用时 CLI 回退，需 OPENAI_API_KEY）。
2. UI 皮精修 + 地形精修（按「单帧不判小作坊」截图自检）。
3. 图标最终态 + 发行说明（README 键位/分发指引）。
- 验收：截图自检通过；verify + build + electron:build:win 三绿；可分发包产出。

### 穿插与闸门
- P1 架构剩余（registry key 类型化/渲染职责拆分/启动配置清理）随每轮小步穿插。
- 每轮纪律：verify 全绿 → build → electron:build:win 刷新 exe；改存档 bump schema + 迁移；多策略模拟（含产布策略）作为数值回归闸门。
- 阶段验收：P1+P2 落地后，主理人 2-4h 自测 + 至少 1 位朋友试玩，输出 playtest 记录（国格到达时间/资源曲线/困惑点清单），据此校准 8h 曲线。
