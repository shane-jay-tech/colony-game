## 原始诉求

主理人要求：把"邦国录"做成 (1) 高度自由、无胜利条件、8h+ 的沙盒主玩法；(2) 跟随小说《天下人书记》、7 章 3 分支（封建/资本/社会主义）的故事模式；两者共用一台引擎。已确认：沙盒先行、时间换质量、叙事克制不喊口号。要求团队压测并交主理人审阅。

## DeepSeek V4 Pro 审核（verdict: do-not-ship · 原文）

**CRITICAL：**
1. 范围现实性：单人非程序员 + AI 辅助，规划 7章×3分支 + 国格引擎 + 双轴 + 全经济重平衡，超个人产能两个数量级，必然烂尾。建议沙盒首发为唯一内容，故事缩为单线至多 2 分支或剥离为 DLC。
2. Phase3 七卷血肉内容量超单人天花板，分支方案未定，易陷"无差异 / 做不完"双输。建议压缩为 5-6 章 × 2 路线，用系统驱动叙事，Alpha 先验证单线长度。
3. 沙盒受众 vs 故事受众心流根本冲突，强行捆绑两头落空（独立游戏常见死法）。建议沙盒为唯一首发，故事改造为可选"历史剧本"；若共存须共享≥80% 系统。

**MAJOR：**
4. 沙盒剔除社会形态轴、故事靠双轴判定，共用引擎导致架构分裂或体验虚假。建议统一引擎：社会形态系统两模式都在，沙盒只作可选政体影响经营、不判结局；故事才锁结局。
5. 春秋开国之君→数百年后赵衍 身份硬切，"时间抹除成就"挫败感强。建议引入传承锚点（祖训/血脉/先王遗命变量）+ 可控过渡叙事。
6. 8h 沙盒仅靠里程碑+国策+张力+美术是单维正反馈，6h 后鼎盛期留存崩。建议每国格设时代目标与危机 + 可选"时代胜利" + 长期工程建筑 + 多维张力（派系/文化/外交）。
7. 隐性双轴全程隐藏 + 共享主干，结局判定时玩家茫然"被审判"，三路差异感薄弱。建议半可视化氛围指示 + 关键分岔立竿见影系统反馈 + 每路≥3 章专属重大事件；产能不足则砍到 1-2 条高差异路线。
8. 直接用"社会主义/资本主义"等现实政治术语，有发行与审查风险（评测轰炸/下架）。建议抽象为架空政体名（公权之道/明君独治/商贾共盟）+ 加强道德灰度。

**MINOR：**
9. 非程序员 + AI coding 缺架构审查，技术债指数上升。建议 Phase1 后引入资深程序员审计 + 强制模块化/自动化测试。

**Nits**：美术钩子依赖产能；8h 数值平衡应 Phase1 最高优先；低谷防刷；章节标题太抽象加副标题；序章教学难度曲线缺失。

**What's good**：国格阶梯是优秀骨架；隐性双轴+氛围反馈有创新潜力。

## Kimi K2.6 调研（原文要点 · 全文另存 docs/decisions/2026-05-31-research-sandbox-story-design.md）

**沙盒长草 6 手法**：①涌现叙事矩阵（事件=f(国格,外部张力,内部风气)）；②分层系统强制耦合（每级国格解锁消费旧产出的新维度，网状依赖）；③动态均势 NPC AI（弱则被欺、强则触发合纵，加蛮夷第三方保证张力不清零）；④跨会话长期工程（铸九鼎/作春秋/复九服，进度常驻可见，当自定目标锚点）；⑤隐性国风变量（尚武/重农…同建筑不同产出，一局点不满，促重开）；⑥扩张带来新约束而非纯奖励。

**7章×3分支控量公式**：主干 80% / 滤镜包装 15% / 独立内容仅 5%（全压到第 5 章）。1-2 章零差异只推轴值；3 章滤镜变体（1框架+3配置）；4 章系统参数化（1系统+3参数表）；**5 章唯一做 3 套独立内容**（会盟/变法/革命），把省下预算全砸这；6 章共享危机框架不同解法；7 章 9 套结局文本。建"典故事件模板库"1:3 放大内容感。

**双模式共存 4 启示**：①Simulation 层 / StoryDriver 层严格分离，剧情靠 storyFlags，故事玩法插件挂载不污染沙盒；②双轨时间（故事 CK3 式自动暂停，沙盒不强制）；③UI 差异化（故事顶栏换章节目标/双轴/距下个分岔）；④数值双表分离（sandbox_balance.json vs story_drama.json，故事覆盖、通关恢复，绝不在共享代码改数值）。**坑**：冰汽时代剧本与无尽难度数值互相污染；帝国时代2 沙盒调参破坏战役教学关；缺氧剧本边界锁死带入沙盒思维挫败。

**风险**：第 5 章 3 套独立内容是单人唯一高风险项，做完雏形再评估是否继续；数值双表必须 Phase2 起就分离否则重构成本极高；建议 3 章完整+4 章大纲上 EA 验证。**置信度：中高 75%**。

## Opus 仲裁（采纳 / 驳回 / 交主理人）

**采纳（已落地设计稿）：**
- Kimi 控量公式（80/15/5，独立内容压第 5 章）→ 直接解 DeepSeek critical#2。
- Kimi 沙盒 6 手法（尤其跨会话长期工程 + 分层耦合 + 动态均势 NPC + 国风变量 + 扩张即约束）→ 直接解 DeepSeek major#6"会无聊"。
- Kimi 引擎分层（Simulation/StoryDriver 分离 + 双表数值 + storyFlags + UI 差异化）→ 解 DeepSeek critical#3/major#4"架构分裂"，无需把社会形态轴塞进沙盒判定。
- DeepSeek major#5 传承锚点 → 加"祖训/先王遗产"叙事桥，缓解隔代硬切。
- DeepSeek major#7 + 我们的 OQ-S2 → 氛围反馈升级为半可视化 + 关键分岔即时系统反馈。
- DeepSeek nits → 8h 数值平衡列 Phase1 最高优先、低谷防刷、章节加副标题、序章难度引导、EA 式增量验证（3章完整+4章大纲）。

**驳回 / 软化：**
- DeepSeek critical#1/#9"非程序员做不了/去雇人"：主理人的工作模式本就是 AI + 多模型协作，这正是缓解手段；据实告知"野心大、靠分期+增量验证扛"，不照搬"雇人"。
- DeepSeek critical#3 极端版"故事剥离成独立游戏/DLC"：驳回拆分，保留双模式，但靠沙盒先行 + 故事分期增量验证落实其"先聚焦"精神。
- DeepSeek major#2"砍到 2 路线"：暂不砍到 2，先按 Kimi 控量做 3 路（差异压第 5 章）；若第 5 章雏形产能不够，再降级为 2 路（已写入风险预案）。

**交主理人拍板（2 个产品决策，超出我的权限）：**
- D1：沙盒要不要引入"可选政体当经营风味"（DeepSeek#4 折中）——还是坚持纯做大做强、零社会形态。
- D2：三路标签用现实术语（社会主义/资本主义，忠于小说）还是抽象架空名（公权之道/商贾共盟，更安全且更合"不喊口号"调性）。

**最终对主理人摘要**：见对话（结论+改动+2决策+风险+反方+置信度）。
