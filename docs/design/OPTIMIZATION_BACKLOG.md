## 每轮纪律

1. 小步提交，commit message 说明验收证据。
2. 每轮：`npm run verify`（type-check + 测试）→ `npm run build` → 出包前 `npm run electron:build:win`。
3. 改存档结构必须 bump `SAVE_SCHEMA_VERSION` + 迁移 + 旧档回归。
4. 任何 UI 改动遵守字号/色板铁律；地图渲染层不得出现格线。
