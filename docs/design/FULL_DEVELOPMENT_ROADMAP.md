## 1. 总体目标与约束

### 1.1 游戏定位
- **类型**：模拟经营为主，军事为辅（锦上添花，不喧宾夺主）
- **时长**：沙盒单局 6-8 小时；故事模式 10-15 小时
- **受众**：自玩 + 小规模朋友圈分享（暂不考虑 Steam）
- **品质基线**：视觉/听觉达到"不被判定为小作坊"，参照纪元 1800 气质

### 1.2 铁律（贯穿全部 Phase）
1. 测试不能破（`npm test` 全绿）
2. 文案半文半白：保留古典韵味但禁偏字，非历史专业玩家一遍看懂
3. 地图无格线：底层可方格，渲染层完全无格线
4. 美术质量基线：单看一帧不能让人判断为小作坊
5. 每次代码落地后自动 `npm run electron:build:win` 刷新 .exe
6. `.bat` 文件必须 GBK + CRLF
7. Console 禁 emoji（GBK codepage 限制）
8. 军事系统永远不能比经济系统占更多玩家注意力
9. **每个 Phase 交付时必须**：(a) SaveSchema 版本号递增 (b) 编写新数据结构的 migration 函数 (c) 验证旧存档能平滑迁移
10. **每个 Phase 结束时**：除单元测试外，需补跨系统集成测试（验证新旧系统交互无 bug）

### 1.3 阶段总览

| Phase | 主题 | 核心交付 | Playtest 节点 |
|-------|------|---------|--------------|
| **A** | 手感打磨 | 沙盒"玩起来舒服" | A 结束后自测 2h |
| **B** | 沙盒深度 | 人口阶层/军事/外交/后期/事件 | B 结束后自测 6h |
| **C** | 故事填肉 | 七卷完整可玩 | C 结束后通关一次 |
| **D** | 美术集中攻关 | 建筑全覆盖 + UI + 将领 | D 结束后截图审美 |
| **E** | 打磨发布 | 平衡/Bug/打包/重玩性 | E 结束后发给朋友 |

## 2. Phase A — 手感打磨

> **目标**：让沙盒模式"玩起来舒服"——有声音、有反馈、有引导、世界有呼吸感。
> **前置**：无（当前状态即可开始）
> **预计任务量**：~12 个任务

### A-1. 音乐系统接入

**做什么**：将已生成的 9 首 BGM 接入游戏，按"国格阶段 × 当前状态"矩阵切换。

**设计意图**：沉默的经营游戏没有沉浸感。音乐是成本最低、感知提升最大的单项改进。

**切换矩阵**：

| | 和平 | 紧张（NPC 敌对/战争准备） | 危机（三低谷/被围攻） |
|---|---|---|---|
| 初期（聚落/城邑） | 质朴田园 | 暗流涌动 | 低沉压抑 |
| 中期（邦国/诸侯） | 恢弘渐起 | 鼓角争鸣 | 紧迫催促 |
| 后期（霸主/天下共主） | 盛世华章 | 大军压境 | 末路悲歌 |

**实现要点**：
- 9 首 BGM 映射到 3×3 矩阵格子
- 切换时淡入淡出（crossfade 2-3 秒）
- 状态判定：和平 = 无敌对 NPC 且无危机；紧张 = 任一 NPC stance ≤ -30；危机 = crisis.active === true
- 音乐循环点设在水印之前（Mureka 生成的 BGM 尾部有水印）
- 玩家可在设置中调节音量（0-100）或静音

**验收标准**：
- [ ] 进入游戏后 3 秒内有音乐播放
- [ ] 国格升级时音乐风格明显变化
- [ ] NPC 宣战时切换到紧张曲目
- [ ] 音量可调、可静音
- [ ] 切换无爆音/跳帧

### A-2. 音效基础层

**做什么**：为核心操作添加音效反馈。

**必做音效（6 个，优先级从高到低）**：
1. 建筑放置（沉稳的"咚"）
2. 建筑完工（清脆的"叮"+ 轻微欢呼）
3. 国格升级（号角/钟鸣，庄严感）
4. 事件弹窗出现（竹简展开的"唰"）
5. 按钮点击（轻敲木头）
6. 资源不足提示（低沉警告音）

**音效来源**：Freesound.org（CC 协议）或 AI 生成。格式 `.ogg`，单文件 < 200KB。

**验收标准**：
- [ ] 6 个音效全部接入并能听到
- [ ] 音效音量独立于音乐音量可调
- [ ] 预加载（Boot scene 中），不实时加载

### A-3. 季节系统（视觉 + 机制）

**做什么**：季节不只是调色——绑定核心经济参数，让时间流逝有玩法意义。

**设计意图**（参考 Banished/Frostpunk）：纯视觉 tint 对 6-8h 体验提升有限；绑定机制后，季节变化成为玩家决策节点（"冬天前必须囤够粮"）。

**四季表现 + 机制绑定**：

| 季节 | 色调 | 机制效果 |
|------|------|---------|
| 春（天 1-90） | 嫩绿/淡粉 | 播种季：农田产出 +30%；建筑工期 -20%（适合开工） |
| 夏（天 91-180） | 深绿/金黄 | 灾害季：洪涝/蝗灾事件概率 ×2；人口自然增长 +50% |
| 秋（天 181-270） | 橙红/棕褐 | 丰收季：所有资源产出 +20%；税收（金）+30% |
| 冬（天 271-360） | 灰白/青蓝 | 休整季：建筑工期 +50%；粮食消耗 +20%；但外交/朝议效率 +30%；远征军耗粮 ×1.5（Phase B 军事系统落地后生效为"禁止远征"） |

**实现方式**：
- `timeSystem` 中按 day % 360 判定季节
- 散布层 tint 按季节调整（渐变 10 天过渡）
- 季节 modifier 注入 `modifierAggregator`
- 冬季加轻量雪花粒子（max 50 粒子）

**验收标准**：
- [ ] 四季色调区分明显，过渡平滑
- [ ] 农田春季产出高于其他季节（可通过资源面板验证）
- [ ] 冬季无法发起远征（按钮灰掉 + 提示）
- [ ] 性能无影响

### A-5. 世界呼吸系统（统一通知层）

**做什么**：合并"随机小通知"和"叙事插曲"为统一系统，按重要性决定显示形式。

**设计意图**：填补正式事件之间的空白，让世界有"在运转"的感觉。一套系统两种表现，避免代码重复。

**两种显示形式**：
- **轻通知（toast）**：1 句话，屏幕右下角浮现 5 秒消失。用于经济/状态提示。
- **报文（bulletin）**：3-5 句话面板，左上角弹出，需点击"知道了"关闭。用于世界动态/叙事插曲。

**触发规则**：
- 轻通知：每 8-12 天触发一条（与正式事件间隔 ≥5 天）
- 报文：每 15-25 天触发一条（沙盒）/ 每 10-15 天（故事模式，带叙事内容）
- 同一条 30 天内不重复
- 内容必须与当前状态相关（条件匹配）

**首版内容量**：
- 轻通知：20 条（覆盖经济/民生/季节/建筑状态）
- 报文：15 条（覆盖 NPC 动态/民间传闻/将领消息）

**验收标准**：
- [ ] 平均每 10 天能看到至少一条通知（轻或报文）
- [ ] 内容与当前状态相关
- [ ] 不打断玩家操作（轻通知不可点击，报文有关闭按钮）
- [ ] 文案半文半白

### A-6. 史官谏言（情境引导系统）

**做什么**：替代传统 JIT 教程，用"史官"角色在玩家首次遇到危机/新系统时给出情境化教学。

**设计意图**（参考 Civ 6 顾问系统）：纯触发点式教程（"第一次建农田时弹提示"）无法应对复杂状态组合。改为"史官"在检测到玩家困境时主动谏言。

**触发机制**：

| # | 检测条件 | 史官谏言内容 |
|---|---------|-------------|
| 1 | 首次进入游戏 | "大人，草庐数十，炊烟初起。先建农田养活众人罢。" |
| 2 | 粮食 < 0 持续 3 天 | "粮已见底！速增农田，或减少徭役人口。" |
| 3 | 金 = 0 且有需要金的建筑在建 | "库银空矣。市集能带来收入，但需先有驿道通商。" |
| 4 | 首次解锁国策面板 | "国策乃百年大计，采纳后不可撤回，望三思。" |
| 5 | NPC stance 首次降到敌对 | "邻邦已露不善，当修兵备、或遣使周旋。" |
| 6 | 人口达到 housing cap | "民无所居。建屋安民方能继续增长。" |
| 7 | 首次国格升级 | "恭喜升格！新建筑和国策已解锁，请查阅建造面板。" |
| 8 | 连续 30 天无建造/无国策采纳 | "大人近日似无作为……是否需要臣提些建议？"（附 2-3 条当前可做的事） |
| 9 | 首次进入危机 | "邦国虽入低谷，但不会亡。坚持住。" |
| 10 | 建筑放置无邻接加成 | "此处无相邻加成。农田近水井可增产三成。" |
| 11 | 季节切换到冬（首次） | "入冬了。冬季不宜远征开工，但适合朝议外交。" |
| 12 | 首次有将领可用 | "有武将来投。可在军事面板中指派出征。" |

**实现方式**：
- 每条谏言只触发一次（存入 save data）
- 显示为特殊面板（与报文区分：有"史官"头像/图标）
- 可在设置中关闭（"关闭史官提示"）
- 条件检测在每日 tick 中执行（性能影响极小）

**验收标准**：
- [ ] 12 个触发点生效
- [ ] 每条只出现一次
- [ ] 不阻断游戏
- [ ] 可全局关闭

### A-7. 事件节奏控制器（状态驱动）

**做什么**：在事件引擎上加一层节奏控制，按国家状态动态调整事件频率。

**设计意图**（参考 Frostpunk 温度驱动事件）：纯时间间隔导致事件与玩家行为脱节。状态驱动让事件成为经营结果的"果"。

**国家状态分级**：
- **太平**：粮 > 储量 50%、金 > 20、无敌对 NPC → 事件间隔 35-50 天
- **发展中**：正常经营、有压力但不危急 → 事件间隔 25-35 天
- **紧张**：任一资源 < 储量 20%、或 NPC 敌对 → 事件间隔 15-25 天
- **危机**：crisis.active === true → 事件间隔 10-20 天（密集）

**硬性规则**：
- 保底：超过 50 天无事件 → 强制触发
- 防连击：两事件间距 ≥ 8 天
- 状态权重：事件池按当前状态筛选（太平时不触发战争事件；危机时不触发"祥瑞"）

**验收标准**：
- [ ] 不出现连续 50+ 天无事件
- [ ] 不出现 8 天内连续 2 个正式事件
- [ ] 危机时事件明显更频繁

## 3. Phase B — 沙盒深度

> **目标**：让沙盒模式有足够深度支撑 6-8 小时不无聊。
> **前置**：Phase A 完成
> **预计任务量**：~25 个任务

### B-0. 人口阶层系统（核心骨架）

**做什么**：引入"农/工/兵/士"四阶层人口分配，让经济运转有真正的决策锚点。

**设计意图**（参考 Anno 1800 人口阶层 + Banished 劳动力分配）：当前系统中"人口"只是一个数字——建筑占用 X 人就行。这导致经营缺乏核心张力。引入阶层后，玩家必须决定"人往哪分"：

**四阶层**：
| 阶层 | 产出/功能 | 消耗 | 来源 |
|------|---------|------|------|
| 农（农民） | 操作农田/桑园，粮食产出 | 粮 1/人/日 | 默认阶层，流民自动入 |
| 工（工匠） | 操作工坊/建筑，工业产出 | 粮 1.5/人/日 + 布 0.2 | 从农晋升（需学塾） |
| 兵（士卒） | 军事力量，不产出资源 | 粮 2/人/日 + 铜 0.3 | 从农征召（需兵营） |
| 士（学者） | 研究速度/外交效率/礼制 | 粮 2/人/日 + 金 1 | 从工晋升（需学宫） |

**核心张力**：
- 分兵多 → 军强但产出降（因为农少了）
- 分士多 → 研究快但养不起（要金要粮）
- 全农 → 产出高但打不过 NPC、研究慢

**与现有系统的关系**：
- 建筑的 `cost.people` 改为指定阶层需求（农田需农 5、铜冶坊需工 5、兵营需兵 6）
- 人口增长仍由 housing + 粮食余量驱动，新增人口默认为"农"
- 国策/朝令可影响晋升速度和阶层效率

**饥饿规则**：
- 粮食余量 < 0 持续 **5 天** → 每天按总人口 **2%** 减少（从最低消耗阶层农开始扣，扣完再扣上一级）
- 粮食余量 < 0 持续 **15 天** → 比例升至 **5%/天** + 民心 -3/天
- 粮食回正后停止减员，但损失不恢复（需重新等待人口增长）
- **底线**：人口不会降到 5 以下（保底存活）

**验收标准**：
- [ ] 人口面板显示四阶层分布
- [ ] 建筑需要对应阶层人口才能运转
- [ ] 阶层切换有时间成本（3-5 天转化期）
- [ ] 阶层不足时建筑产出为 0 且有警告
- [ ] 饥饿减员按规则触发
- [ ] ≥15 个单元测试覆盖阶层逻辑

**建筑-阶层需求映射**（Phase B 落地时据此改 `cost.people` → `cost.{farmer|worker|soldier|scholar}`）：

| 建筑 | 需求阶层 | 人数 |
|------|---------|------|
| 农田 / 桑园 | 农 | 5 / 4 |
| 伐木场 / 采石场 | 农 | 2 / 3 |
| 铜冶坊 / 冶铁坊 / 织官 / 水碓 | 工 | 5 / 5 / 8 / 3 |
| 兵营 / 练兵场 / 马厩 / 战车坊 / 禁军府 | 兵 | 6 / 8 / 6 / 8 / 12 |
| 学塾 / 学宫 / 天文台 / 监察台 | 士 | 2 / 4 / 4 / 5 |
| 市集 / 驿道 / 驿站 | 工 | 4 / 6 / 4 |
| 祖庙 / 石碑场 / 客馆 / 太庙 | 士 | 3 / 6 / 4 / 8 |
| 民居 / 水井 / 王宫 / 仓廪 / 城墙 / 哨塔 | 无 | — |

### B-1. 军事系统

#### B-1.1 兵种体系

**设计原则**：军事收益体现为"防御性价值"——避免损失、外交杠杆、威望积累。不是盈利手段。

**具体"防御性收益"**（对比纯经济路线）：
- **威慑**：军力 > NPC 1.5× 时，NPC 不会主动攻击（省下被劫掠的损失）
- **外交杠杆**：军力强时外交选项更多（逼降/威慑成功率高）
- **威望**：胜战 +信誉，信誉影响 NPC 态度和贸易条件
- **掠夺**：有资源回报，但扣除兵员损失+粮草消耗后净收益 ≈ 同期经营的 60-80%（打仗不亏但也不如种田）

**兵种进化表**：

| 国格 | 可用兵种 | 解锁条件 | 攻/防/粮耗 |
|------|---------|---------|-----------|
| 城邑 | 民兵 | 兵营 | 3/4/2 |
| 邦国 | 步卒、弓兵 | 兵营 + 征兵国策 | 6/5/3、5/3/2 |
| 诸侯 | 精锐步卒、骑射、战车 | 练兵场/马厩/战车坊 | 9/8/5、8/4/4、12/6/6 |
| 霸主 | 禁卫军、攻城器械 | 禁军府 | 15/12/8、6/2/4 |

#### B-1.1b 士气规则

- 初始值：80
- 胜仗 +20（上限 100）
- 败仗 -30（下限 10）
- 粮草不足时 -5/天
- 将领"鼓舞"特质：士气不会低于 50
- 战斗中士气 < 30 → 溃败（自动撤退，额外损兵 20%）

#### B-1.1c 威慑出征效果

- 消耗：粮草 = 兵力 × 0.3 × 2 天
- 效果：目标 NPC 关系 +20、60 天内不攻击玩家
- 失败条件：我方军力 < 目标 NPC 军力 × 0.8 → 威慑无效，白耗粮草

#### B-1.1d 附庸状态

- 触发：连续 3 次被攻击未迎击
- 效果：每季缴金 5 + 粮 10 给攻击方
- 解除条件：军力 > 对方 2× 时可发起"独立"出征（视为攻城战），或通过外交"挑拨"让宗主被第三方攻击后自动解除

#### B-1.2 出征系统

**流程**：配置 → 派出 → 等待（3-10 天）→ 30% 概率途中事件 → 结算

**出征前配置**：
- 编成（选兵种+数量，上限 = 当前兵阶层人口的 80%）
- 将领（可选，有加成）
- 粮草（消耗 = 总兵力 × 0.5 × 天数，不够会提前撤退）
- 目标类型：劫掠（3-5 天）/ 威慑（2-3 天）/ 攻城（7-10 天）

**结算公式**：
```
我方战力 = Σ(兵种攻击力 × 数量) × (1 + 将领统率/100) × 士气 × min(1, 实际粮草/需要粮草)
敌方战力 = NPC.military × (1 + 城墙修正0.3) × 随机(0.85-1.15)
胜率 = 我方 / (我方 + 敌方)
```

**结果**：
- 胜（胜率 > 0.6）：获目标收益，损兵 10-20%
- 惨胜（0.4 < 胜率 ≤ 0.6）：获部分收益，损兵 30-50%
- 败（胜率 ≤ 0.4）：无收益，损兵 50-70%，NPC 反击概率 +40%

#### B-1.3 防御系统

**NPC 攻击流程**：
1. 预警（5-10 天）："某邦调兵遣将" 报文通知
2. 玩家配兵迎击（同出征界面，目标=迎击）
3. 结算（公式同上，玩家加主场加成 +20%）
4. **不迎击后果**：NPC 自动获胜，掠夺资源 = 玩家当前储量的 15-25%（不会清零、不会灭亡）

**失败底线（明确定义）**：
- 国家**永远不会灭亡**
- 最坏情况：资源被掠 25%、人口损失 10%、国格不降
- 连续 3 次被攻击未迎击 → 触发"附庸"状态（每季缴贡，但可通过后续外交/军事解除）

### B-2. 将领系统

**上限**：同时最多 4 位将领。

**将领属性**：
- **统率**（5/10/15/20）：战力加成百分比

**获取方式**：

### B-3. NPC 系统重做

#### B-3.1 随机生成

**NPC 模板池**：预设 8 个（每局随机选 4 个）。

每模板含：
- 国名（架空）+ 性格（好战/商贸/保守/扩张）
- 初始国力 = 玩家初始 × 随机(0.7-1.3)
- 偏好外交手段

**生成约束**：
- 4 个中至少 1 好战 + 1 商贸
- 随机一对 NPC 天然敌对（产生外交操作空间）
- 另加 1 个"蛮夷"周期犯边（固定角色，不算在 4 个里）

#### B-3.2 外交操作

| 操作 | 条件 | 效果 | 持续 |
|------|------|------|------|
| 朝贡 | 对方军力 > 我 1.3× | 每季缴金 5，对方不攻击 | 5 季 |
| 贸易协定 | 关系 ≥ 0 | 双方 +3 金/日 | 60 天 |
| 联姻 | 关系 ≥ 30 + 礼器 10 | 关系锁定 +50 | 120 天 |
| 结盟 | 关系 ≥ 50 | 被攻击时盟友自动援兵 | 无限（可单方解除） |
| 威慑 | 军力 > 对方 1.5× | 对方 30 天不攻击 | 30 天 |
| 挑拨 | 金 20 + 信誉 10 | 两 NPC 关系 -40 | 即时 |

#### B-3.3 NPC 军力推算

NPC 不维护兵种明细，用简化公式估算：

```
NPC.military = NPC.national_power × 0.4 × personality_mul
  personality_mul: 好战 1.3 / 扩张 1.1 / 商贸 0.8 / 保守 0.9
NPC.national_power 初始 = 玩家初始 × random(0.7, 1.3)
  每 30 天增长：+= 2 × (1 + 游戏天数/360)   // 随时间线性变强
```

对战时 NPC 战力直接用 `NPC.military`（不拆兵种），玩家战力按兵种明细公式计算。

#### B-3.4 NPC AI（简单规则）

```
每 30 天 NPC 决策一次：
- if 玩家军力 < 自身 0.7× and 关系 < -20 → 准备攻击（5-10天后执行）
- if 玩家军力 > 自身 2× → 寻求贸易/朝贡
- if 另一 NPC 军力 > 自身 1.5× → 向玩家求盟
- if 均势被打破（一家独大）→ 其他 NPC 联合对抗强者
```

### B-4. 后期内容

#### B-4.1 阶层博弈（替代消极贪腐）

**设计意图**（参考 Frostpunk 法案 + CK3 派系）：后期挑战不是"数字越来越负"的 debuff，而是政治博弈事件链。

**机制**：人口 > 80 后，出现三大势力（豪强/外戚/士人），各有诉求：
- **豪强**：要求减税 → 拒绝则民心 -5/月，接受则金产出 -20%
- **外戚**：要求封赏 → 拒绝则忠诚 -10，接受则占用 1 国策位
- **士人**：要求开放朝议 → 拒绝则研究 -20%，接受则结局轴向"公天下"倾斜

**处理方式**：通过建筑（监察台）/国策（肃贪/开明）/朝令来管理。
- 每 60-90 天触发一次阶层博弈事件
- 与三结局挂钩（如何处理这些势力影响双轴）

#### B-4.2 巨型工程

| 工程 | 阶段 | 总耗时 | 关键消耗 | 完成奖励 |
|------|------|--------|---------|---------|
| 铸九鼎 | 3 阶段 | 90 天 | 铜 200 单位 + 礼 100 单位 | 信誉 +50 + 永久威慑（NPC 不主动攻击） |
| 作春秋 | 5 阶段 | 150 天 | 布 100 单位 + 金 200 单位 + 占用士 10 人 | 研究速度永久 +30% |
| 修直道 | 4 阶段 | 120 天 | 石 300 单位 + 木 200 单位 + 占用农 30 人 | 所有建筑产出 +10% + 贸易效率 +50% |

**注**：若已达天下共主，铸九鼎改为"永久威慑"（NPC 永不主动攻击）替代国格直升。

#### B-4.3 国策互斥

后期（诸侯+）解锁的国策出现互斥组：
- "重商主义" vs "重农主义"（选一锁一，影响金/粮产出比例）
- "扩军备战" vs "休养生息"（军力 +50% vs 全资源 +15%）
- "开放边贸" vs "闭关锁国"（金 +20% + 间谍风险 vs 安全但收入低）

## 9. 性能铁律

- 全场景任意时刻活跃粒子 **≤ 300**
- 同屏同时执行 tint 变更的对象 **≤ 20**（采用脏标记 + 每帧最多处理 5 个 tint 操作）
- NPC AI 决策 tick **每 30 天一次**，单次 < 1ms
- 事件条件检测 **每日 tick**，采用短路求值，单次 < 0.5ms
- 后期（40+ 建筑）帧率 ≥ 30fps

## 10. 关键设计原则

1. **经济为王**：所有系统通过经济连接。军事消耗人口/粮食、外交影响贸易、巨型工程是资源黑洞。
2. **人口是核心稀缺**：四阶层分配是贯穿全局的核心决策（参考 Anno 1800）。
3. **简单规则涌现复杂度**：NPC AI 只有 4 条 if-else，但组合行为多变。
4. **军事克制**：如果 playtest 发现军事比经营更有趣 → 削弱军事回报。
5. **文案是灵魂**：宁少勿烂。每条事件须有画面感、不超过 5 句。
6. **季节有意义**：不只是换色——绑定经济参数，让时间流逝成为决策节点。
7. **内容量可控**：首版控制在可完成范围内（40 沙盒事件 + 35 故事决策 + 56 报文），后续可扩展。
8. **测试保障**：每系统 ≥10 单元测试 + 每 Phase 结束时跨系统集成测试。
