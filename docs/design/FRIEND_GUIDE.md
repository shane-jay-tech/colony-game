# 邦国录 · 给朋友的三分钟上手

你是一座春秋小邦的当家人。种田、立市、修国策、会盟邻邦，一级级往上爬：
聚落 → 城邑 → 邦国 → 诸侯 → 霸主 → 天下共主；或者进「故事」模式，亲历一部
「把龙椅拆掉」的七卷长剧。

## 一分钟：先活下去

1. 点左侧建造栏，选「农田」，放到地图上——时间开始流动。
2. 顶栏是全部家当：粮、木、石、钱、民、布、铜、礼。**点任意资源数字**，可看
   它每天进多少、出多少（「每日出入」面板）；入不敷出会直接告诉你建什么补。
3. 粮食不够就补农田、木石不够补伐木/采石——先把温饱稳住。

## 一分钟：往上升一格

1. **点顶栏国格徽章**（写着「聚落」的小金匾），会列出升下一格的条件：
   人口/钱/布/标志建筑，缺什么一目了然，逐项打勾。
2. 照着补：升城邑要人口 30、钱 80、建「市集」；升邦国要布 40、建「祖庙」……
3. 布从「桑园」来，铜从「铜冶坊」来，礼从「祖庙/太庙」来——面板里的
   「补X：某某可建」会告诉你。

## 一分钟：玩出花样

- **国策树**（顶栏「朝堂」）：永久加成，像科技树一样点，有的二选一互斥。
- **邦交**（顶栏「邦交」）：通商、出使、结盟、宣战。列国警惕值高会合纵围攻你。
- **军务**（顶栏「军务」）：招将、出征。军事是防御性的——养兵为了不被欺负。
- **史官**（顶栏「史官」）：花名望搞宣传、斡旋、修史。
- **大业**（顶栏「大业」）：铸九鼎、作春秋，后期的资源黑洞与终极目标。
- **功业分**（顶栏「记」）：一生功业的多维计分，登顶/通关自动结算。
- **三幕大势**（工具栏中段）：群狼环伺 → 诸侯会盟 → 末世裂变，天下局势随时间变。

## 你永远不会死

崩盘不会 Game Over：会进低谷（民变/借贷/割地），稳住收支就能爬回来。
沙盒没有终点，登顶「天下共主」后继续经营，扛终局风浪。

## 小抄

- 拖动平移、滚轮缩放；空格暂停，`>`/`>>`/`>>>` 加速。
- 顶栏「?」是典册（百科），随时查。
- 顶栏「档」三槽存档/读档。
- 故事模式：序章（统一天下）→ 七章剧情事件 → 三结局（公/家/货）。

玩得开心。有什么看不懂、不好玩的，都记下来告诉开发者——这游戏还在长。
