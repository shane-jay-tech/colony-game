# 邦国录 · 标杆游戏调研与扩展方案

> **性质**：外部标杆玩法调研 → 本作映射 → 可落地扩展方案（含优先级/成本/验收标准）。
> **调研对象**：纪元 1800（Anno 1800）、城市天际线（Cities: Skylines）、冰汽时代（Frostpunk）、缺氧（Oxygen Not Included）、钢铁雄心 4（HOI4）、群星（Stellaris）。
> **约束**：一切扩展服务于已拍板的核心——沙盒「8h 做大做强」+ 故事「社会形态演变」双支柱、四根长线钩子、国格阶梯脊梁、军事不喧宾夺主（铁律 #8）、地图无格线、文案半文白。

## 一、逐游戏拆解：它好在哪 → 本作能拿走什么

| 游戏 | 核心机制优点（它为什么好玩） | 与本作契合点 | 结论 |
|---|---|---|---|
| **纪元 1800** | ①生产链纵深：原料→半成品→成品，每级需要更高阶层劳动力；②城市吸引力/美化驱动布局；③「报纸+影响力」：花稀缺影响力改写舆论换短期民心；④贸易航线跨岛协作 | 已有 8 资源经济 + 阶层（士农工商）与建筑 `classType`，缺中间品纵深与「美观度」反馈 | 采纳加工链、美观度、影响力三项 |
| **城市天际线** | 市民有明确需求（水电医教），服务覆盖决定幸福度→税收与建筑升级；需求是「让城市运转」的持续优化题 | 人口阶层已有，但住房只是人数容器；把「需求满足度」变成驱动生产效率与升格的活性系统 | 采纳「阶层需求环」 |
| **冰汽时代** | **希望/不满双米**是所有个体需求的聚合出口，每个决策即时结算道德代价；法律书让「治国路线」本身成为玩法 | 本作已有 0–100 士气单维 + 国策互斥，但道德代价不直观；双米可直接让「仁政/峻法」的抉择被看见 | 采纳双轴民心（最高价值项） |
| **缺氧** | ①系统耦合：产出必带副产品，副产物逼出下一个系统（经典链式优化）；②房间组合加成奖励空间规划；③岗位技能需求 vs 士气 | 与 Anno 的邻接加成合并成同一机制「组合/邻接」；副产品可作为可选深度层 | 采纳组合加成；副产品标记「慎用」 |
| **钢铁雄心 4** | ①国策树把长线规划可视化（已 HOI4 化落地）；②**世界紧张度**：全局张力值调节宣战成本与结盟门槛，让「打得动/打不动」有节奏闸门 | 春秋均势 NPC 已设计但缺一个玩家可读的全局张力表 | 采纳「列国警惕值」 |
| **群星** | ①异常点/考古链：探索产出多阶段分支叙事，喂给「涌现故事」；②中期危机+终局危机把 4X 的后期空虚填满；③传统/飞升树制造每局不同 build | 本作已有点位事件与危机低谷，缺「探索链」与「登顶后的持续危机」 | 采纳古迹事件链 + 终局危机升级 |

## 二、采纳清单（按优先级）

### A1 · 双轴民心「民心 / 怨愤」（★最高 · Frostpunk）

- **现状**：`playerMorale` 0–100 单维；朝令/事件加减值后不可见地影响危机。
- **改造**：拆成两根 0–100 的公开条（民心=希望，怨愤=不满），事件/朝令/国策即时结算「代价提示」（如「峻法：+怨愤 12，短期治安 +2」）；怨愤超阈值触发民变诉求（复用 `factionSystem` 的诉求模态），民心超阈值给颂声加成。
- **为什么是本作第一杠杆**：故事模式的社会形态抉择（封建/资本/社会主义）本质是道德抉择；双米把「看不见的代价」变成每次点击都看得见的张力，直接服务叙事基调与危机低谷模型。
- **落地边界**：不改存档结构（`playerMorale` 保留，新增 `publicWrath` 字段走 schema v4 迁移）；HUD 顶栏加一对米 + 变色警告；朝令/国策数据补 `morale`/`wrath` 影响字段。
- **验收**：沙盒 1h 内至少出现一次「民愤临界→诉求/民变」的可见因果链；所有朝令在面板上标注民心/怨愤代价；旧存档迁移后两米有合理初值。

### A2 · 阶层需求环（★高 · Cities:Skylines + ONI 士气）

- **现状**：阶层有 `computeClassConsumption` 与住房容量，但「服务覆盖」只影响个别建筑效率。
- **改造**：为每阶层定义需求表（农夫：粮食/安居；工匠：工具/市集；士人：礼器/教化；商贾：布匹/驿道），需求满足度 = 对应建筑是否建成 + 资源余量，聚合成「民足」系数乘到生产效率与人口增长率；需求缺口显示在 PopulationPanel 的阶层卡上。
- **验收**：缺市集时工匠产出有可见折扣、补齐后恢复；PopulationPanel 每个阶层可查「当前需求缺口」；不改变无头模拟的收敛性（P0-1 断言通过）。

### A3 · 组合/邻接加成（美观度 + 房间）（★中高 · Anno 1800 + ONI）

- **现状**：建筑有国格排面但无空间决策；地图无格线是铁律，邻接判定用等距网格坐标即可（渲染不变）。
- **改造**：定义轻量组合规则（民宅×水井/市集、工坊×水源、礼制建筑×宗庙），在 `productionSystem` 旁加 `computeAdjacencyBonuses`，产效率 +1~3%；同时给 HUD 建筑悬浮「组合提示」。
- **验收**：纯函数邻接计算有单测；加成不破坏建造自由（无强制布局）；等距坐标系下边界 tile 正确。

### B1 · 列国警惕值「天下侧目」（★中高 · HOI4 世界紧张度）

- **现状**：`npcDynamics` 按玩家军力触发合纵/围攻，但玩家看不到「我离被围攻还有多远」。
- **改造**：新增 0–100 全局 `worldWariness`：玩家扩军/称霸/宣战 +值，通商/和亲/纳贡 −值；阈值闸门调节 NPC 结盟速度与围攻概率（现有 `computeNpcAlliances` 加权）。HUD 邦交面板显示当前档位与「侧目原因」。
- **验收**：警惕值到阈值后一周内出现可观察的合纵/围攻动作；和平手段能把它压回安全档；沙盒中后期张力不再「突然糊脸」。

### B2 · 影响力资源 + 史官宣传（★中 · Anno 影响力/报纸）

- **现状**：史官只有氛围评语（`historianSystem`），无玩家能动用的「舆论」手段。
- **改造**：新增资源 `influence`（影响力，产出源=国格+史官+朝令），可花在：①宣传（短期 +民心 / −怨愤，效果递减）；②外交斡旋（降低列国警惕）；③史官修史（+国风值）。消耗型资源制造「何时用」的决策。
- **验收**：影响力有稳定产出/消耗闭环，UI 有入口；宣传效果有时间衰减并在文案中体现「粉饰不能持久」。

### B3 · 加工链纵深（中间品）（★中高 · Anno 1800）

- **现状**：8 资源 + 建筑直接产出，链条浅（粮→人口，铜→军备）。
- **改造**：数据驱动加 2–3 条中间品（麻布：麻→布；青铜：铜+锡→青铜；礼器：玉+工匠→礼器），中间品建筑受阶层与邻接加成双重约束。落在 `data/buildings.ts` + `productionSystem`，不新建引擎。
- **验收**：无头模拟在中后期仍有「解不开的瓶颈」而非数值平推；新建筑全部有美术占位或成品图。

### C1 · 古迹事件链「山河探秘」（★中 · Stellaris 异常点/考古链）

- **现状**：地图有资源点，事件是全局抽样的「朝议」。
- **改造**：地图新增古迹点类型，点击派遣「史官/工匠」触发 2–3 阶段分支事件链（挖掘→抉择→回报），复用 `eventEngine` 的多分支；事件文案走半文白与禁偏字铁律。直接喂「涌现叙事矩阵」（B.1.1 #1）。
- **验收**：一条完整 3 阶段链可玩通；选项后果差异可感知（资源/民心/国风三选二）；古迹点数量随地图种子变化。

### C2 · 终局危机升级「八方来朝」（★中 · Stellaris 终局危机）

- **现状**：登顶天下共主后开放无限玩，但压力曲线没有明确升级。
- **改造**：登顶后启动「天下共主」压力阶梯：每 N 日随机抽天灾/合纵/四方来犯一波，强度随持续天数递增，扛住给「盛名」软奖励——给开放式终局一个持续心跳，避免 6h 后空虚（B.1 的 6h 腻点）。
- **验收**：登顶后 2h 内至少两波可感知压力事件；玩家可继续无限经营；压力曲线在无头模拟中不导致必然崩盘。

## 三、标记「慎用 / 不采纳」及理由

| 机制 | 来源 | 结论与理由 |
|---|---|---|
| 交通/道路流量模拟 | 城市天际线 | 不采纳：春秋小邦无机动交通，尺度不符 |
| 流体/热力/气体物理模拟 | 缺氧 | 不采纳：复杂度爆炸，偏离「经营+叙事」主题 |
| 军编制微操/装备流水线 | HOI4 | 不采纳：违反铁律 #8（军事不得喧宾夺主），保留现有军备抽象 |
| 星系级探索尺度 | 群星 | 部分采纳：以「古迹事件链」降维替换，不做大地图扩张 |
| 强制终局时限（Frostpunk 式倒计时） | 冰汽时代 | 不采纳：沙盒开放式已拍板（B.4）；改为 C2 的无限波次压力 |
| 副产品/废料链 | 缺氧 | 慎用：深度好但易变噪音，排在加工链（B3）之后，若 8h 仍缺后期难题再上 |
| 随机科技卡池 | 群星 | 慎用：与「系统只提示不下命令」的沙盒哲学可能冲突，先靠隐性国风（B.1.1 #5）解决重开差异 |

## 四、与本作已拍板设计的关系（防止方向打架）

- A1 双轴民心是「危机低谷 + 史官 + 社会形态轴」的**显示层统一**，不新增胜负条件，不违背「沙盒纯做大做强、社会形态只在故事模式」。
- B1 列国警惕值是「动态均势 NPC（B.1.1 #3）」的**可视化与闸门化**，不是新外交系统。
- C1 古迹链是「涌现叙事矩阵（B.1.1 #1）」的**空间化触发器**，不替代全局朝议事件。
- B3 加工链是「分层系统强制耦合（B.1.1 #2）」的**具体链条实现**。
- 全部条目落地时遵守：测试不破、存档版本号+迁移、`npm run electron:build:win` 刷新 exe、每 Phase 补跨系统集成测试。

## 五、执行顺序建议（并入 OPTIMIZATION_BACKLOG）

1. **P2 手感段**：A1 双轴民心 → A2 需求环 → A3 邻接加成（三项共享「把人口/民心变成可见优化题」的同一目标，一起做数值联调）。
2. **P2 手感段**：B1 列国警惕值（直接增强钩子 3 外部张力）。
3. **P3 内容段**：B3 加工链 → B2 影响力/宣传 → C1 古迹链 → C2 终局危机。
4. 每项落地后跑 P0-1 无头模拟回归，用模拟数据校准新数值。
