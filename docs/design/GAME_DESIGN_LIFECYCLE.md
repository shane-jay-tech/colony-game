## 1. 核心定位与幻想

> 状态：✅ 大方向已定（双支柱），细节继续填

### 1.1 结论：双支柱结构

经讨论，邦国录定为**两种模式并存、共用底层经营系统**：

- **支柱一 · 沙盒主玩法（拍板：走 B 路线）**
  - 一局 **8 小时以上**的自由经营，玩家自己探索、自己定目标、自己玩。
  - 系统**只给提示，不下命令**（不强制通关、不规定打法）。
  - 这是游戏的脊梁，乐趣在"把邦国越养越好、看它生长"。
- **支柱二 · 故事模式（叙事线）**
  - 分章分节（参考《天下人书记》七卷结构），带**意识形态分支**。
  - 主线走向**社会主义 / 共产主义**（小说原案："拆龙椅"）。
  - 关键节点可**分支**：固守**封建主义** / 异化成**资本主义** / 走向社会主义，每个节点不同走向。

### 1.2 重大发现：游戏与《天下人书记》本就同源

剧本源文件：`D:\论文集\天下人书记.docx`（已抽取纯文本到 `docs/design/_tianxiaren_source.md` 供实现 agent 读取）。

《天下人书记》= 七卷四十五年政治寓言，穿越者皇帝赵衍把绝对权力逐步交还人民、最终撤掉龙椅。核心命题：**"共产党人不是来坐江山的，是来拆龙椅的。"**

**关键事实**：当前 v1.0 春秋设定，其实已经是这部小说意象的"春秋转换层"——开发者早有此意图：

| 小说意象 | 游戏春秋化身 | 代码注释佐证 |
|---|---|---|
| 灯塔（卷五·人类命运共同体） | 烽燧 `bld_beacon_tower` | "灯塔→烽燧 意象转换" |
| 蒸汽机车轮（卷四·生产力） | 水碓 `bld_water_mill` | "蒸汽机意象转换：以水替力" |
| 油菜花（卷二/卷七·人民事业） | 桑园 `bld_mulberry_grove` | "油菜花意象转换" |
| 石碑·刻大白话不刻圣旨（卷二核心） | 石碑场 `bld_stele_yard` + 朝令 `decree_stele_market` | "勒石于市，使民共见" |

**推论**：游戏现有的"为君之道（兵威）vs 为民之道（信誉）"道德轴，是小说核心命题"一小撮人吃天下人 vs 天下人养天下人"的游戏化种子。故事模式 = 把《天下人书记》做成可玩的。

### 1.3 ⚠️ 待解决的关键结构问题（下一节先啃这个）

**设定时代错位**：游戏现在是**春秋·青铜·小邦**（无皇帝、无蒸汽机）；但小说《天下人书记》是**虚构王朝大梁·帝制 + 蒸汽机 + 海军 + 殖民公司**（约等于帝制晚期到工业时代）。两者时代差极大。

故事模式必须先回答：沙盒（春秋）和故事（大梁）的设定怎么调和？候选思路（待第 2/6 节细化）：
- **A 纯转换**：故事模式仍留在春秋，把小说主题"再转换"一遍（如现有意象做法），"拆龙椅"→拆某种春秋权力结构。
- **B 跨时代**：故事模式是一条横跨多个时代的长线，沙盒春秋只是开端，往后推进到大梁时代兑现小说剧情。
- **C 换皮同引擎**：春秋沙盒与大梁故事是同一套经济/国策系统的两套"皮"，故事模式直接用大梁设定。
- **D 社会形态分支即剧情**：意识形态（封建/资本/社会主义）本身作为分支轴，故事模式= "你的邦国演化成哪种社会形态"，与沙盒"建国"和小说"制度变革"都能咬合。
- **✅ 已拍板：D + B 组合**。故事模式 = "从春秋起步、随剧情跨时代演化、用社会形态（封建/资本/社会主义）分岔、以『拆龙椅』为终极结局"的长线叙事。
  - 时代错位由此化解：前期春秋皮（烽燧/水碓），后期社会工业化后揭开真身（灯塔/蒸汽机）。
  - 👑 **终极胜利条件 = 自我消解**：玩家不是靠最强通关，而是成功把权力溶解进制度、最后亲手撤掉龙椅。封建/资本两路是"没走到那一步"的另两种结局。
  - 详见下方【故事模式设计（支柱二）】专章。

## 沙盒模式设计（支柱一 · 主玩法）

> 状态：🚧 弧线初稿，讨论中

### B.1 已定：四根长线钩子（撑起 8h+ 高度自由）

经讨论选定 **1+2+3+5**（钩子 4"显式玩法流派"**砍掉**——与"高度自由/自己定义"冲突，流派改为靠国策树自然涌现，系统不命名不引导）：

1. **成长里程碑（脊梁·给奔头）**：国格一级级往上爬，每级解锁新内容+排面，但永不"结束"。
2. **国策/科技树的"再深一点"拉力（《文明》式再来一回合）**：把现有 23 条国策 + 升级链做深，制造"想点出终极节点"的欲望。
3. **外部张力（心跳·不让你太舒服）**：齐晋鲁会自己成长/结盟/找茬，天灾随时代变大；光盖房子会腻，要有"狼来了"。
4. **建造与美术纯粹爽感（texture）**：无格线 + 纪元级美术，看着草庐长成宫阙、越来越好看。

判断：**1+3 是骨架（里程碑给奔头、张力给心跳），2+5 是血肉**。纯靠盖房好看撑不满 8h。

#### B.1.1 撑住 8h 的 6 个具体机制（团队压测后补 · 解"6h 后会腻"）

DeepSeek 警告纯里程碑+美术是"单维正反馈"，6h 后留存崩；Kimi 调研给出可迁移手法，采纳：

1. **涌现叙事矩阵**：事件 = f(国格, 外部张力, 内部国风)。同一典故（如葵丘会盟）在不同国家状态下目标/后果全不同 → 每局不一样。
2. **分层系统强制耦合**：每级国格解锁一个"消费旧系统产出"的新维度（商路吃粮食盈余→外交吃礼乐→礼乐吃工匠→工匠吃粮食），织成网状依赖，玩家一直有新的优化难题（直接服务"甲·经营优化"）。
3. **动态均势 NPC**：齐晋鲁有"春秋均势逻辑"——玩家弱→NPC 互打+骚扰你；玩家强→自动触发合纵/尊王攘夷联盟围你。加"蛮夷"第三方，保证任何阶段外部张力不清零。
4. **跨会话长期工程**：铸九鼎 / 作春秋 / 复九服 等多阶段大工程，进度常驻可见，成为玩家自定"本局目标"的锚点（兼作 DeepSeek 要的"可选时代目标"）。
5. **隐性国风变量**：尚武/重农/好辩等隐藏值，让同一建筑产出不同，一局点不满 → 促不同风格重开。
6. **扩张带来新约束而非纯奖励**：畿外新城邑带来治理成本/土壤限制等，每块新地是优化难题不是涂色奖励。

| 城邑 | 筑城聚民，立稳脚跟 | 中级建筑、首批国策 | 夯土城墙 |

### B.3 🚧 草案：8 小时弧线（节奏曲线）

- **阶段一·生存（聚落→城邑，约 0–1h）**：温饱挣扎、第一次危机（灾/匪）。难度小高峰建立"心跳"。
- **阶段二·立国（城邑→邦国，约 1–3h）**：经济多元化（布/铜/礼器）、国策树打开、初通邦交。系统逐步展开。
- **阶段三·扩张（邦国→诸侯，约 3–6h）**：国策深点、邦交张力升级（战/盟）、灾害变大、城渐美（美术回报）。
- **阶段四·鼎盛（诸侯→霸主→天下共主，约 6–8h+）**：系统全开、世界全反应、冲顶；此后**开放式无限延续**（经营/求存/求美）。

### B.4 已定

### 11.B 手感 / Juice

> 状态：✅ 方向已定

**现状体检**：世界 100% 静止（无炊烟/行人/流水/旗帜/飞鸟，建筑为静态图无动画帧）；仅地图层有少量"选中脉冲"tween；放置/完工/资源变动/相邻加成基本无动效音效反馈。→ "纪元 vs 小作坊"观感差距主要在此。

    2. 飘字**不满天飞**：只跟当前聚焦的楼 + 整体增长靠 HUD 滚动；限流、快淡出。
    3. **按缩放分级(LOD)**：拉远抑制单栋微反馈（只留 HUD 级 + 活的世界动效），拉近才显示细节。

- **C·操作手感**：放置预览 + 落定"咚"（动效+音效+扬尘）、施工进度→完工庆祝、按钮/面板开合过渡。

## 故事模式设计（支柱二）

> 状态：🚧 七卷映射初稿，讨论中

### S.1 总结构：序章（春秋）→ 七章（大梁化跨时代）→ 三结局

**叙事脊梁 = 跟随《天下人书记》七卷**，但前置一个"春秋立国序章"作为桥接（小说没写的"这个国家怎么来的"），也复用沙盒的经营教学。随剧情推进，邦国从春秋小邦壮大成大梁式王朝，社会逐步工业化，小说的桥段依次解锁。

三条社会形态之路（玩家的累积选择决定走向）：
- **社会主义路（小说原案 / 正典）**：持续选 为民/信誉、技术归公、自我革命反腐、分田、让权 → 终局**拆龙椅**。
- **封建路（固守）**：权力始终集中、不彻底分田、靠兵威与民心管控 → 终局**"明君王朝"**（稳定但停滞，龙椅仍在，王朝终将循环——小说暗讽的那种）。
- **资本路（异化）**：技术归私、重商铸币、放任贫富分化 → 终局**资本主义**（富强但异化，天下人重新"被一小撮人吃"）。

### S.3 待讨论的开放问题

- **✅ OQ-S1 已定：跳变派。**
  - **序章 = 独立的教学引导关卡**：三个底层身份开局（复用现有 IntroScene 的 小邦君/流亡公子/国人推举领袖）→ 用现有经营/国策/邦交/军事系统一步步教 → **序章胜利条件 = 统一天下**（小邦统一 = 王朝诞生）。
  - **时代跳变靠"统一→建朝"事件触发**，紧接一段**旁白/过场**：时间快进很久，交代王朝建立后这一千年间发生了什么（为第一章"旧秩序已腐化"做铺垫）。
  - 过场结束 → 进第一章「血堤」，正式进入大梁王朝时代与社会变革主线。
- **✅ OQ-S5 已定：玩家身份 = 甲（同一血脉·隔代轮回），但纯叙事不靠肉鸽。**
  - 序章你是开国之君；过场后隔代，第一章你成了几百年后已腐化王朝的君主（赵衍）。核心情感：**亲眼看到自己理想建起的国烂成最痛恨的样子，于是"革自己祖宗的命"**——与卷三"自我革命"主题同源。
  - "隔代接力"是剧情/过场手法，不是死亡重开循环。
- **✅ 砍掉肉鸽层 + 重定失败模型**（推翻 v1.0 设计）：
  - **删除**「天命碎片」跨局永久 buff 系统（与 8h 沙盒、与七章叙事都冲突）。
  - **统一哲学**：邦国录没有 Game Over，只有"走向不同结局"和"需要爬出来的低谷"。
    - 沙盒：经济崩盘 → 可翻身的危机（丢地/掉人口/被邻邦逼成附庸），留在同一局爬回来。
    - 故事：输不掉剧情，糟糕选择把你推向较差结局（封建/资本）或可挺过的挫折（参照小说沈逸尘下狱、石敢牺牲）。
  - 现有 `src/renderer/data/defeat.ts` 的「流亡」可**保留改造成"低谷之一"**（可恢复），但去掉 `retainTechRatio` 跨局逻辑与天命碎片。
  - ⚠️ 实现 agent 注意：这会动到 `defeat.ts` 及相关 system + 测试，属破坏性改动，需重写对应测试。

- **✅ OQ-S2 已定：隐性累积（慢慢成长），不做显式"选主义"按钮。**
  - 后台两根隐藏轴：**权力轴**（集权↔还权于民，即现有"为君/为民"的延伸）+ **生产资料轴**（私有↔公有）。
  - 玩家**每一次抉择**（国策、朝令、事件选项、🔀大节点）都在悄悄推这两根轴；不止看大节点。
  - 三路 = 两轴区域：集权+私有=封建；还权+私有(工业)=资本异化；还权+公有=社会主义(拆龙椅)。
  - **反馈方式**：机制数字全程隐藏；只给**氛围化/在地化反馈**（史官评语、民间流言随风向飘），玩家感觉得到趋势但摸不到后台轴。"自由地走，但走得明白。"
  - （待最终确认：氛围反馈保留 vs 连氛围也藏、纯结局揭晓。当前倾向保留氛围反馈。）
- **✅ OQ-S4 已定：同一台引擎。**
  - 底层只有一套自由经营沙盒引擎（地图/资源/建筑/国策/邦交全共用）。
  - **沙盒模式** = 引擎裸跑，无剧本、无限玩、**高度自由**、玩家自定目标。
  - **故事模式** = 同一引擎 + "叙事导演"层（注入章节目标与剧情事件、推进隐性双轴、兑现结局），**手牵紧一点**（比沙盒更强的引导）。
  - 章节推进靠**达成目标解锁**（不按时间硬推），导演按玩家进度喂剧情，防"晾着剧情自顾自盖房"导致节奏垮。
- **✅ OQ-S3 已解（团队压测采纳 Kimi 控量公式）**：**主干 80% / 滤镜包装 15% / 独立内容仅 5%（全压到第 5 章）**。
  - 1-2 章：零差异，小选择只悄悄推隐性轴值（1 套内容）。
  - 3 章：滤镜变体（1 套危机框架 + 3 套配置表/对话）。
  - 4 章：系统参数化（1 套经济系统 + 3 份 JSON 参数表，井田/市易/均田）。
  - **5 章：唯一做 3 套独立内容**（封建会盟 / 资本盐铁官营+贵族叛乱 / 社会国人暴动+分地）——把前 4 章省下的预算全砸这里，制造最强选择重量。
  - 6 章：共享危机框架，仅解法不同。 7 章：9 套结局文本变体。
  - 另建"春秋典故事件模板库"：1 套机制 + 3 套叙事文本，1:3 放大内容感。

### S.4 团队压测后的设计修订（2026-05-31）

详见归档 `docs/decisions/2026-05-31-review-lifecycle-design.md`。采纳要点：
- **传承锚点（解 DeepSeek：隔代硬切挫败）**：序章开国之君临终留"祖训/先王遗产"，赵衍继承部分物质或精神遗产 + 一段可控的"王朝衰败"过渡叙事，让身份转换可理解、不突兀。
- **结局透明度（解 DeepSeek：被审判感）**：氛围反馈升级为**半可视化**（如朝堂风格渐变、可窥探的"民心倾向"），且每个 🔀关键分岔必须有**立竿见影的系统级反馈**（如分田后自耕农产出升、贵族不满触发事件），让玩家走得明白。

- **章节副标题**：血堤/淬火等抽象标题加一句通俗副标题，降低理解门槛。

### S.5 ✅ 主理人已拍板的两个产品决策（2026-05-31）

- **✅ D1 · 沙盒保持纯粹**：沙盒**不引入**任何政体/社会形态，纯"做大做强"。社会形态系统仅存在于 StoryDriver 层（故事专属）。靠 8.1 引擎分层 + 双表数值保证不分裂。
- **✅ D2 · 三路用架空名（不用现实政治术语）**，取自《礼记·礼运》"天下为公/为家"轴，纯古典、零现实指涉、且贴合"不喊口号"调性：
  | 架空名 | 含义（世界观语言） | 对应社会形态 | 结局 |
  |---|---|---|---|
  | **公天下** | 天下为公（《礼运》大同） | 社会主义/共产主义 | 拆龙椅·大同 |
  | **家天下** | 天下为家，权位当家业传承 | 封建固守 | 明君王朝（停滞循环） |
  | **货天下** | 天下为货，万物皆可贸易私有 | 资本异化 | 富强却异化（天下人复被一小撮人所食） |
  - 实现 agent 注意：游戏内一律用 公天下/家天下/货天下，**禁用** "社会主义/资本主义/封建主义" 等现实术语；史官评语、事件文本均以世界观语言表达。
  - 文学根：公天下结局 = 《礼记·礼运》"大道之行也，天下为公"，正是小说《天下人书记》精神的古典原话。

## 3. 核心循环（两模式共用）

> 状态：✅ 已定

三层嵌套：
- **分钟级（心跳）**：看一眼缺啥 → 补一手（盖楼/调民/应对弹窗）→ 城市动一下、数字变好。
- **季节/年级（节律）**：四季轮转 → 周期事件（夏蝗/秋涝/冬耗粮）+ 收成结算 + 国策朝令推进一截 + 邦交冷却刷新。
- **整局级（弧线）**：沙盒爬国格阶梯 / 故事推章节。

**✅ 核心"爽点动词" = 甲（经营优化）**：玩家分分钟在"发现瓶颈（粮不够/闲民闲置/卡某资源）→ 调整布局解决 → 国力上台阶"。
- **设计含义**：经济链与建筑布局必须**深、耐抠**（供应链、相邻加成、资源转化）——这是 8h 长线的主拉力，实现优先级最高。
- 事件 / 邦交 = **心跳与调味**（punctuate，不喧宾夺主），不是主菜。

## 6. 主题与叙事基调

> 状态：✅ 基调已定

- **沙盒模式**：无主题包袱，纯"做大做强"。
- **故事模式**：主题轴 = **权力（集权↔还权）+ 生产资料（私有↔公有）**，源自现有"为君/为民"，终点是小说命题"拆龙椅"。
- **⚠️ 叙事基调铁律（写给实现 agent，极重要）**：
  - 跟随《天下人书记》原则——**通过情节本身呈现理念，绝不使用概念化口号**。小说全程不喊"社会主义万岁"，而是用石碑刻大白话、拆裹脚布、马援朝的堕落、撤龙椅来"演"出来。

  - 文案延续半文半白 + 避偏字（见第 0 节铁律）。

### 8.1 引擎分层架构（团队压测采纳 · 防"两模式共用引擎分裂"）

- **Simulation 层（共用）**：地图/资源/建筑/国策/邦交核心模拟，沙盒与故事都跑这层，绝不被故事逻辑污染。
- **StoryDriver 层（故事专属，插件式挂载）**：章节目标、剧情事件、隐性双轴、结局判定全在此层，通过 `storyFlags` 与 Simulation 层交互，故事玩法以插件挂上去，不动沙盒代码。
- **数值双表分离（极重要，Phase2 起就必须做，否则重构成本极高）**：`sandbox_balance.json`（沙盒 8h 曲线）vs `story_drama.json`（故事戏剧化数值，如刻意制造粮荒）。故事模式用 drama 表**覆盖**沙盒表，通关后恢复——**绝不在共享代码里改数值**。
- **双轨时间**：故事模式 CK3 式自动暂停（剧情事件触发→timeScale=0）；沙盒不强制暂停。
- **UI 差异化**：故事顶栏换"当前章节目标/权力轴/生产资料轴/距下个分岔 N 事件"；沙盒留原始经营数据。
- **教训（前车之鉴）**：冰汽时代剧本与无尽难度数值互污染；帝国时代2 为沙盒调参破坏战役教学关 → 双表分离就是防这个。

## 9. 缺口与风险清单

> 状态：🚧 草案

1. **内容量爆炸（最大风险）**：故事模式 7 章 × 3 分支。缓解 = 共享主干，只在结局+关键节点（专利公私/让权）做分支变体（OQ-S3）。
2. **8h 经济平衡**：现无 8h 调参经验，曲线难调，需反复 playtest。
3. **题材敏感性**：意识形态题材——靠小说式"克制、用情节说话、不喊口号"化解（见第 6 节），避免说教感与争议。
4. **叙事导演节奏**：故事模式若玩家晾着剧情自顾盖房 → 章节靠"达成目标解锁"而非时间硬推。
5. **范围现实性**：单人开发 + 非程序员主理 → **必须分期、沙盒先行**（见第 10 节），不可一次性吃下全部。
6. **美术产能**：新建筑/国格排面需达"纪元级"基线；产出节奏可能成瓶颈（`art-library` + `gen_wanxiang_batch.py` 已有管线）。
7. **数值双表互污染（团队新增）**：为沙盒调一次粮产可能破坏故事某章刻意的粮荒设计 → **Phase2 起就双表分离**（见 8.1），事后重构成本极高。

> **团队压测加权**（2026-05-31，详见 `docs/decisions/2026-05-31-review-lifecycle-design.md`）：DeepSeek 对整体范围判 do-not-ship，核心理由即风险 #5（范围）+ #1（内容量）；缓解策略 = 沙盒先行 + 故事增量验证（3章完整+4章大纲）+ Kimi 控量公式（独立内容仅 5%）。第 5 章 3 套独立内容是单人开发唯一高风险项，做完雏形再决定保 3 路或降 2 路。

## 附录 A：v1.0 玩法现状快照（已盘点，事实层）

- **设定**：春秋早期一个小诸侯国当家人，从底层视角白手起家。标题「春秋小邦立国志」。
- **开局**：取邦名 → 三选一身份（小邦君 / 流亡公子 / 国人推举领袖，各带永久 modifier + 开场楔子）→ 抛出"为君之道（兵威）vs 为民之道（信誉）"主题。
- **时间**：1 年 = 120 天 = 4 季 × 30 天，可暂停/加速，逐日结算。
- **资源（8）**：粮/木/石/钱/闲民（前期）+ 布/青铜/礼器（中后期阶层）。
- **建筑（约 20）**：民生/工坊/礼制/军事/科技五类，1~3 级，可升级链，有相邻加成，多数受国策门控。
- **国策树（23，仿 HOI4）**：农桑/工坊/礼制/保甲/外交/学问 6 支，每支 ≥3 层，含 3 处二选一互斥（重粮⊕重桑、商道⊕兵道、车马⊕舟师）。
- **朝令（12）**：5 类递进链，每条 2 阶段（先 add 即时收益，后 mul 放大）。
- **事件**：天灾（蝗/旱/涝）、盗匪、求援、献艺等，多为"为君 vs 为民"双选。
- **邦交**：3 NPC 国 齐(商)/晋(武)/鲁(礼)，可通商/出使/兴师，开战看军力比。
- **失败（无 Game Over）**：国库+存粮双零撑满 60 天 → 流亡卫国边邑，人口砍到 20、建筑降级、清资源，保留 50% 科技 + 攒 1 枚天命碎片（永久 buff）。
- **❗缺口**：无任何明确"胜利目标"，为君/为民两条道无终局兑现。
