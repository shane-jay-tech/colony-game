## 1. 核心定位与幻想

> 状态：✅ 大方向已定（双支柱），细节继续填

### 1.1 结论：双支柱结构

经讨论，邦国录定为**两种模式并存、共用底层经营系统**：

- **支柱一 · 沙盒主玩法（拍板：走 B 路线）**
  - 一局 **8 小时以上**的自由经营，玩家自己探索、自己定目标、自己玩。
  - 系统**只给提示，不下命令**（不强制通关、不规定打法）。
  - 这是游戏的脊梁，乐趣在"把邦国越养越好、看它生长"。
- **支柱二 · 故事模式（叙事线）**
  - 分章分节（参考《天下人书记》七卷结构），带**意识形态分支**。
  - 主线走向**社会主义 / 共产主义**（小说原案："拆龙椅"）。
  - 关键节点可**分支**：固守**封建主义** / 异化成**资本主义** / 走向社会主义，每个节点不同走向。

### 1.2 重大发现：游戏与《天下人书记》本就同源

剧本源文件：`D:\论文集\天下人书记.docx`（已抽取纯文本到 `docs/design/_tianxiaren_source.md` 供实现 agent 读取）。

《天下人书记》= 七卷四十五年政治寓言，穿越者皇帝赵衍把绝对权力逐步交还人民、最终撤掉龙椅。核心命题：**"共产党人不是来坐江山的，是来拆龙椅的。"**

**关键事实**：当前 v1.0 春秋设定，其实已经是这部小说意象的"春秋转换层"——开发者早有此意图：

| 小说意象 | 游戏春秋化身 | 代码注释佐证 |
|---|---|---|
| 灯塔（卷五·人类命运共同体） | 烽燧 `bld_beacon_tower` | "灯塔→烽燧 意象转换" |
| 蒸汽机车轮（卷四·生产力） | 水碓 `bld_water_mill` | "蒸汽机意象转换：以水替力" |
| 油菜花（卷二/卷七·人民事业） | 桑园 `bld_mulberry_grove` | "油菜花意象转换" |
| 石碑·刻大白话不刻圣旨（卷二核心） | 石碑场 `bld_stele_yard` + 朝令 `decree_stele_market` | "勒石于市，使民共见" |

**推论**：游戏现有的"为君之道（兵威）vs 为民之道（信誉）"道德轴，是小说核心命题"一小撮人吃天下人 vs 天下人养天下人"的游戏化种子。故事模式 = 把《天下人书记》做成可玩的。

### 1.3 ⚠️ 待解决的关键结构问题（下一节先啃这个）

**设定时代错位**：游戏现在是**春秋·青铜·小邦**（无皇帝、无蒸汽机）；但小说《天下人书记》是**虚构王朝大梁·帝制 + 蒸汽机 + 海军 + 殖民公司**（约等于帝制晚期到工业时代）。两者时代差极大。

故事模式必须先回答：沙盒（春秋）和故事（大梁）的设定怎么调和？候选思路（待第 2/6 节细化）：
- **A 纯转换**：故事模式仍留在春秋，把小说主题"再转换"一遍（如现有意象做法），"拆龙椅"→拆某种春秋权力结构。
- **B 跨时代**：故事模式是一条横跨多个时代的长线，沙盒春秋只是开端，往后推进到大梁时代兑现小说剧情。
- **C 换皮同引擎**：春秋沙盒与大梁故事是同一套经济/国策系统的两套"皮"，故事模式直接用大梁设定。
- **D 社会形态分支即剧情**：意识形态（封建/资本/社会主义）本身作为分支轴，故事模式= "你的邦国演化成哪种社会形态"，与沙盒"建国"和小说"制度变革"都能咬合。
- **✅ 已拍板：D + B 组合**。故事模式 = "从春秋起步、随剧情跨时代演化、用社会形态（封建/资本/社会主义）分岔、以『拆龙椅』为终极结局"的长线叙事。
  - 时代错位由此化解：前期春秋皮（烽燧/水碓），后期社会工业化后揭开真身（灯塔/蒸汽机）。
  - 👑 **终极胜利条件 = 自我消解**：玩家不是靠最强通关，而是成功把权力溶解进制度、最后亲手撤掉龙椅。封建/资本两路是"没走到那一步"的另两种结局。
  - 详见下方【故事模式设计（支柱二）】专章。

## 故事模式设计（支柱二）

> 状态：🚧 七卷映射初稿，讨论中

### S.1 总结构：序章（春秋）→ 七章（大梁化跨时代）→ 三结局

**叙事脊梁 = 跟随《天下人书记》七卷**，但前置一个"春秋立国序章"作为桥接（小说没写的"这个国家怎么来的"），也复用沙盒的经营教学。随剧情推进，邦国从春秋小邦壮大成大梁式王朝，社会逐步工业化，小说的桥段依次解锁。

三条社会形态之路（玩家的累积选择决定走向）：
- **社会主义路（小说原案 / 正典）**：持续选 为民/信誉、技术归公、自我革命反腐、分田、让权 → 终局**拆龙椅**。
- **封建路（固守）**：权力始终集中、不彻底分田、靠兵威与民心管控 → 终局**"明君王朝"**（稳定但停滞，龙椅仍在，王朝终将循环——小说暗讽的那种）。
- **资本路（异化）**：技术归私、重商铸币、放任贫富分化 → 终局**资本主义**（富强但异化，天下人重新"被一小撮人吃"）。

## 附录 A：v1.0 玩法现状快照（已盘点，事实层）

- **设定**：春秋早期一个小诸侯国当家人，从底层视角白手起家。标题「春秋小邦立国志」。
- **开局**：取邦名 → 三选一身份（小邦君 / 流亡公子 / 国人推举领袖，各带永久 modifier + 开场楔子）→ 抛出"为君之道（兵威）vs 为民之道（信誉）"主题。
- **时间**：1 年 = 120 天 = 4 季 × 30 天，可暂停/加速，逐日结算。
- **资源（8）**：粮/木/石/钱/闲民（前期）+ 布/青铜/礼器（中后期阶层）。
- **建筑（约 20）**：民生/工坊/礼制/军事/科技五类，1~3 级，可升级链，有相邻加成，多数受国策门控。
- **国策树（23，仿 HOI4）**：农桑/工坊/礼制/保甲/外交/学问 6 支，每支 ≥3 层，含 3 处二选一互斥（重粮⊕重桑、商道⊕兵道、车马⊕舟师）。
- **朝令（12）**：5 类递进链，每条 2 阶段（先 add 即时收益，后 mul 放大）。
- **事件**：天灾（蝗/旱/涝）、盗匪、求援、献艺等，多为"为君 vs 为民"双选。
- **邦交**：3 NPC 国 齐(商)/晋(武)/鲁(礼)，可通商/出使/兴师，开战看军力比。
- **失败（无 Game Over）**：国库+存粮双零撑满 60 天 → 流亡卫国边邑，人口砍到 20、建筑降级、清资源，保留 50% 科技 + 攒 1 枚天命碎片（永久 buff）。
- **❗缺口**：无任何明确"胜利目标"，为君/为民两条道无终局兑现。
