# 邦国录 v0.10.0 · 发行说明

## 一句话

春秋小邦经营游戏：沙盒爬国格阶梯 8 小时，故事走七卷长剧三结局。存档 schema v9（旧档自动迁移）。

## 本版新增（v0.9 → v0.10）

- **信息可视化**：点顶栏资源数字 → 「每日出入」面板（日产/日耗/净变 + 入不敷出补阙因果链 + 民足系数）；点国格徽章 → 「升格之途」（下一格还差什么逐项打勾）。
- **目标感**：功业记分牌（顶栏「记」，登顶/结局自动结算，历史最高）；三幕大事件时间轴（群狼环伺→诸侯会盟→末世裂变，工具栏常显幕名）；**民愤通牒**（怨愤≥85 限期压平，HUD 倒计时，到期民变）。
- **故事填肉**：七卷剧情事件 23→35（每卷 5 条，取材小说高光场景）；剧情事件节奏修复（每章约 50-60 天走完，不再被沙盒节拍拖垮）。
- **质量**：测试 1025→1076（含故事全流程无头试玩、存档 v1→v9 全链迁移回归、色板/字号/禁偏字永久守护）；registry 类型化、相机数学纯函数化。

## 系统一览

- 8 资源（含麻/锡中间品、名望）/ 35 建筑 / 23 国策 / 12 朝令 / 40+ 沙盒事件 / 6 级国格阶梯
- 双轴民心（心/怨）、阶层需求环、列国警惕值、影响力史官三用、古迹事件链、终局波次、低谷可翻身（无 Game Over）
- 故事：序章统一（武/文双途）→ 七章 → 公天下/家天下/货天下三结局
- 动态音乐（9 BGM 随国格/危机/结局切换）+ 6 音效
